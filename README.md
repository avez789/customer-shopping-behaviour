### Customer Shopping Behavior Analysis

Analyzed **3,900 customer transactions** to understand customer spending patterns, product preferences, customer segments, and subscription behavior.

**Tools:** Python (Pandas), SQL, MySQL, Power BI

**Key Work:**

* Cleaned and prepared the dataset using Pandas.
* Performed EDA using `df.info()`, statistical analysis, and data exploration.
* Analyzed customer demographics, purchases, discounts, ratings, and subscriptions.
* Created SQL queries to generate business insights.
* Built an interactive **Power BI dashboard** with key KPIs and visualizations.

**Key KPIs:** Total Sales, Average Purchase Amount, Customer Count, Average Rating, and Subscription Analysis.
